## 🛠️ 关于本站

一个摆烂的站和一个摆烂的博主，记录一些生活，爱好技术和相关的东西。

这个网站使用 **Astro** 框架构建，采用了 [Firefly](https://github.com/CuteLeaf/Firefly) 模板，Firefly 是基于 [Fuwari](https://github.com/saicaca/fuwari) 的二次开发。

------

## 🔧 魔改了什么

在 Firefly 的基础上又加了一层自己的东西。改动原则是**尽量不碰上游源文件** —— 全部落在 `src/config/**`、`public/**` 素材和**新增**的独立文件上，这样上游更新时几乎不用解冲突。

**首页**

- 壁纸装饰层：毛玻璃个人卡片 + 可拖拽的 Q 版场景贴纸，卡片开场停留两秒后自动收起（可手动收/放）
- 横幅下方一条横向滚动的站长动态条

**页面**

- `/moments/` **朋友圈**：把所有友链的 RSS 聚成一条时间线，来源按 本站 3 / Blog 4 / 社区 3 的配比交错
- `/analytics/` **站点统计**：总览、访问脉冲、推送热力图、活跃时间、地域分布，数据走 Umami 公开分享接口
- `/steam/` **游戏库**：拥有游戏数、总时长、等级徽章与全部游戏时长榜，定时任务写快照
- `/guestbook/` **留言板**：群聊风格的聊天窗口（气泡、成员列表、公告栏、表情、回复/编辑/删除、30 秒自动同步），后端复用自建 Waline
- `/bangumi/` **番组计划**、`/dynamic/rss.xml` **站长动态订阅源**
- `/blog-changelog/` **博客日志**：逐版记录本站的每一次改动
- **友链页 / 书签导航**：卡片悬停展开对方首页截图；友链支持 GitHub Issue 表单自助申请，机器人自动校验后写入配置
- 全站侧栏「最近评论」（只在博客首页显示）

**视觉与性能**

- 全站卡片统一 2px 深色描边（暗色下自动切纯白），自建页也一并补齐
- 壁纸全量转 WebP、贴纸按需加载、关闭 Swup 视口预取、静态资源分层缓存 —— 首屏体积累计砍掉数百 KB

**工程**

- **内容与主题分离**：文章存放在私有仓库，构建前由脚本同步到 `src/site-content/`，主仓库只留主题代码与配置
- **构建期兜底**：外部接口不可达时先探测再回退本地数据，不让一次超时带走整次构建

完整的改动清单见站内 [`/blog-changelog/`](https://www.9ll.uk/blog-changelog/)。
