## 🛠️ 关于本站

一个摆烂的站和一个摆烂的博主，记录一些生活，爱好技术和相关的东西。

这个网站使用 **Astro** 框架构建，采用了 [Firefly](https://github.com/CuteLeaf/Firefly) 模板，Firefly 是基于 [Fuwari](https://github.com/saicaca/fuwari) 的二次开发。

------

## 🔧 魔改了什么

在 Firefly 的基础上又加了一层自己的东西。改动原则是**尽量不碰上游源文件** —— 全部落在 `src/config/**`、`public/**` 素材和**新增**的独立文件上，这样上游更新时几乎不用解冲突。目前是 48 版改动。

**首页**

- **玻璃个人卡片** — 壁纸区叠一层毛玻璃卡片：头像、站名、快捷导航、社交按钮、胶带装饰，依次浮入
- **可拖拽的场景贴纸** — 19 张素材、桌面铺 11 张，按住可拖、刷新复位；素材按需加载，手机端只显示 4 张
- 卡片停留约 2 秒后自动滑出（可手动收 / 放），右下角开关一键隐藏贴纸
- 贴纸给下滑箭头让路（底部那排中央留空）、移动端卡片按屏高抬升让位
- 横幅下方一条横向滚动的站长动态条
- 关闭桌面与移动端的水波纹 canvas 动效

**页面**

- `/moments/` **朋友圈**：把所有友链的最新文章聚成一条时间线，来源按 本站 / Blog / 社区 配比交错
- `/analytics/` **站点统计**：总览、访问脉冲、推送热力图、活跃时间、设备与地域分布、评论统计，数据走 Umami 公开分享接口
- `/bangumi/` **番组计划**：浏览器实时拉 bgm.tv 收藏（动画 308 部 / 看过 277 部）
- `/steam/` **游戏库**：拥有游戏数、总时长、等级徽章与全部游戏时长榜
- `/guestbook/` **留言板**：群聊风格的聊天窗口（气泡、成员列表、公告栏、表情、回复 / 编辑 / 删除、30 秒自动同步），后端复用自建 Waline
- `/blog-changelog/` **博客日志**：逐版记录本站的每一次改动
- `/dynamic/rss.xml` **站长动态订阅源**：与动态页同一份数据
- **书签导航**：卡片悬停展开该站首页截图，图片真悬停过才请求

**友链**

- 卡片悬停展开对方首页截图
- GitHub Issue 表单自助申请，机器人自动校验可达性 / 同域 / 回链后写入配置
- 「博客社区」那批单独分区，不和博客混排；头像统一防盗链

**评论区**（自建增强，全部走页脚注入）

- **回复默认展示 2 条**：多出来的收进「展开更多（还剩 M 条）」，每次再放 5 条，摊完可「收起回复」
- **回复带上引用**：把被回复的那句摘成引用块，点击滚到原评论并高亮
- **动态页也走同一套**：动态的内嵌评论是个 iframe，由父页面把样式与脚本代投进去
- 全站「最近评论」：头像、昵称、相对时间、「评论于 /路径」

**视觉与交互**

- 全站卡片统一 2px 深色描边（暗色下自动切纯白），自建页也一并补齐
- 页脚两行数字：建站运行时间逐秒跳 + 今日 / 全站访客与访问指标
- 顶栏 1024–1599px 挤压修复、「开往」入口与「关于」菜单补自建服务

**性能**

- 壁纸全量转 WebP q90（14.3 MB → 1.0 MB）、贴纸图压到显示尺寸、按需加载
- 关闭 Swup 视口预取 —— 首屏少传 483 KB、少发起 14 个请求
- 站内搜索预热 Pagefind 加载链，取数请求 45 → 6，补上「回车 = 进第一条结果」
- 静态资源分层缓存（哈希资源一年、素材 30 天），部署后自动预热边缘缓存

**工程**

- **内容与主题分离**：文章存放在私有仓库，构建前由脚本同步到 `src/site-content/`，主仓库只留主题代码与配置
- **内容推送自动部署**：内容仓 push 后触发两个平台的部署挂链
- **构建期兜底**：外部接口不可达时先探测再回退本地数据，不让一次超时带走整次构建
